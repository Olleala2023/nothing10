## Что нужно знать сразу

**Источник правды для приложения — `src/app/`.** Каталог `app/` в корне репозитория —
устаревший артефакт сборки. Имена файлов совпадают, содержимое разошлось. Правка в `app/`
не даёт ни ошибки, ни эффекта: код не попадает в сборку.

**Мёртвый код, который легко принять за рабочий:** `src/main.ts`, `src/counter.ts`,
`src/typescript.svg` — нетронутый шаблон Vite. TypeScript в проекте фактически не используется,
несмотря на `tsconfig.json` и зависимость в `package.json`.

**`public/.htaccess` не работает.** Хостинг — Cloudflare Pages, формат Apache он не читает.
Защитных заголовков в production нет.

**Тестов и линтера пока нет.** ESLint установлен без конфигурации, `npm run lint` и `npm test`
не существуют. Требования из `docs/TESTING.md` при этом действуют: выполняются вручную.

## Короткая версия правил

- Ветка на задачу, прямые коммиты в `main` запрещены — Cloudflare деплоит `main` автоматически.
- Conventional Commits: `fix(app): keep countdown running when the screen turns off`.
- Не упоминать в коммитах и артефактах модель ИИ, версию ассистента или номер сессии.
- Не коммитить собранные артефакты.
- Исправление бага начинается с падающего теста — независимо от размера правки.
- `console.log` не попадает в production.
- `!important` в CSS запрещён; цвета — только через CSS-переменные.
- Не подставлять данные в `innerHTML`; SVG создавать через `createElementNS`.
- Отсчёт времени — от `Date.now()`, не декрементом счётчика.
- Календарные даты — локальные, не через `toISOString()`.
- Каждое обращение к `localStorage` — в `try/catch`; новый ключ вносится в реестр
  в `docs/ARCHITECTURE.md` **и** в `public/legal/privacy.html`.
- Документация на русском, код и коммиты на английском. Не смешивать внутри файла.
